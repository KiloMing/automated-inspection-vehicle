# 从差速仿真到麦克纳姆实车

本次范围：提交F407底盘代码和信息，并更新项目主线；保留原F103和ROS工程以便追溯。原README见 legacy-project-2026-11-02.md。历史部署环境与实测记录仍以旧文档为依据。

后续工作：
1. 审核现有URDF/SDF与控制插件，迁移至四轮全向模型；设置轮径80mm、轴距/轮距195mm。验证vx、vy、wz三个独立方向，不沿用差速约束。
2. 新建ROS串口桥：订阅cmd_vel，按20Hz发送车体速度；明确上游命令失效处理，不能重复刷新旧目标来绕过下位机超时。解码24字节CRC包，处理序号回绕、时间戳回绕和MCU重启。
3. 把角度从度转换为弧度/四元数，发布odom与odom->base_link；拒绝NaN，明确时间戳和协方差。下位机归零代表本地odom原点，不是地图map原点。
4. 调整Nav2全向速度限制与控制器、机器人footprint；检查仿真和实车接口一致。当前协议仅回传位姿，没有直接携带实际twist，若需要可差分估计并滤波或扩展协议。
5. 依次完成串口回环、架空轮测、地面直行/横移/转弯、里程标定、建图定位与巡检。每一步单独记录结果，不把原差速建图验证视作麦轮验证。
