# STM32F407 麦克纳姆底盘

Keil 5 工程：`MDK-ARM/F407_HAL_Template.uvprojx`。芯片 STM32F407VET6，HAL，外部晶振8MHz、系统168MHz。用户自行编译下载；本次发布未编译、未烧录。

## 控制与配置

`User/main.c` 调用 `Hardware/ChassisControl.c`。约10ms更新四轮PID；四轮独立状态，初始参数在 MotorATune.h：Kp=1.5、Ki=0.2、Kd=0（输入计数/秒，输出千分比PWM）。MotorATune旧调试入口不在当前主循环运行。ChassisConfig.h 配置几何、超时与遥测周期。

轮径80mm，每圈4000计数；前后/左右轮中心距离均195mm；轮速目标统一比例限幅0.48m/s。PWM最大100%。轮序 A左前、B左后、C右前、D右后。逆运动学：A=x-y-0.195z，B=x+y-0.195z，C=x+y+0.195z，D=x-y+0.195z。

|功能|引脚/定时器|
|---|---|
|A PWM/方向|PE6 TIM9_CH2 / PB15、PD1|
|B PWM/方向|PE11 TIM1_CH2 / PD2、PD3|
|C PWM/方向|PE13 TIM1_CH3 / PD4、PD5|
|D PWM/方向|PE14 TIM1_CH4 / PD6、PD7|
|A编码器|PA0/PA1 TIM2|
|B编码器|PA6/PA7 TIM3|
|C编码器|PD12/PD13 TIM4|
|D编码器|PC6/PC7 TIM8|
|上位机/蓝牙|USART3 PC10 TX、PC11 RX，115200 8N1|
|HWT101|USART2 PA3 RX接传感器TX，115200 8N1|

使用TTL串口并共地，核对模块电平。电机方向软件反转A/B；编码器符号A=-1、B=-1、C=+1、D=+1。安装接线改变后需逐轮核实：正向轮速对应正编码反馈。

## 启动与坐标

上电5秒保持静止，随后清零PID、编码器与位置，并将有效HWT101航向设零。启动期间丢弃命令。原点为此时底盘中心，固定X朝前、Y朝左、角度逆时针为正。四轮实测速率经正运动学得到车体速度，用HWT101航向旋转到固定坐标系后积分。不是IMU加速度积分。航向辅助控制默认关闭。

航向初始无效或运行中超过300ms未更新时，坐标失效并停止积分，需静止重启建立新原点；坐标故障本身不触发停车，运动命令仍受300ms接收超时保护。轮子打滑、方向错误和航向漂移会造成里程误差。

## 接收运动命令

每50ms发送 `[v,0.1,0,0]` 表示车身向前0.1m/s，`[v,0,0,0]` 停止。字段为vx、vy、wz（m/s、m/s、rad/s）。完整有效命令刷新计时，300ms未收到则停止四轮并清零积分，下一有效命令恢复。无CRC；无效帧不刷新计时。

## 发送位姿：50Hz，24字节，小端

|偏移|字段|
|---|---|
|0..1|AA 55|
|2|01 类型|
|3|18 十六进制（整帧24字节）|
|4..5|uint16序号，每次计划发送递增，回绕；忙时跳帧也递增|
|6..9|uint32上电毫秒数|
|10..13|IEEE754 float32 X（米）|
|14..17|IEEE754 float32 Y（米）|
|18..21|IEEE754 float32 O（度），[-180,180)，左正右负|
|22..23|CRC16/MODBUS，低字节先|

CRC覆盖前22字节，初值FFFF，多项式A001，无最终异或。无效位姿三个字段均为0x7FC00000（NaN）。异步发送忙则跳过，不能用FireWater直接解析。

例：序号100、时间8000ms、(0.12m,0.05m,90度)：

```text
AA 55 01 18 64 00 40 1F 00 00 8F C2 F5 3D CD CC 4C 3D 00 00 B4 42 55 0C
```

接收方缓存拆包/粘包，校验帧头、类型、长度、CRC；失败滑动一字节重新同步。ROS侧角度需转为弧度，NaN不得发布为有效位姿。
