# HWT101 接入与角度闭环接口

## 接线和运行

HWT101 TX -> PA3 (USART2 RX)，RX -> PA2 (USART2 TX)，共地。
使用 TTL 电平，模块供电和 IO 电平按实物规格接线。USART2 为 115200、8N1。
USART1 调试口保留 PA9/PA10、9600、8N1。模块当前约 10 Hz 输出。
电机运行由 main.c 初始化与 PWM 调用决定；HWT101 命令不控制电机。
首次校准应让设备静止，再发送 z；首次有效角度自动作为临时参考零点。

## 文件和调用

- Hardware/HWT101.c/h：USART2 配置、中断字节缓冲、快照读取。
- Hardware/HWT101_Parser.c/h：可独立测试的 11 字节协议解析及角度处理。
- User/stm32f10x_it.c：USART2_IRQHandler 调用 HWT101_RxIRQ。
- User/main.c：主循环持续 Poll，编码器约 100 ms 采样，综合状态约 200 ms 输出。

先 Delay_TickInit，再 HWT101_Init；主循环反复 HWT101_Poll。
HWT101_Read(&data) 返回 1 才代表有新鲜航向；不代表本次是新帧，用 sequence 判断。
HWT101_Zero() 只改 MCU 软件参考角，不发送模块配置命令；无新鲜数据返回 0。
接口仅供主循环调用，中断只调用 HWT101_RxIRQ。不得并发操作解析器。

## 数据定义

- yaw_deg：模块 Z 轴角，[-180,180)。不是地理北向绝对航向。
- heading_deg：相对零点角，[-180,180)。
- continuous_deg：从归零起的连续转角，可超过一圈；必须检查 continuous_valid。
- yaw_rate_dps：相邻 yaw 帧最短差除以真实帧间隔，单位 deg/s；必须检查 rate_valid。
  这是角度差分估计，不是 0x52 帧的原始陀螺角速度，10 Hz 下不能反映快速瞬态。
- timestamp_ms：最后一个有效角度帧末字节的接收时间，不是打印/处理时间。
- sequence：每个有效 0x53 帧递增，用于防止控制器对同一数据重复积分。
- valid：最后有效角度距当前不足 500 ms。500 ms 是通信监测阈值，不是未来闭环的推荐延迟。

0x53 使用帧索引 6/7 的有符号小端值乘 180/32768，前十字节和的低八位校验。
索引 8/9 保留，不当作温度；截图中的该字段为版本数据。
0x52 校验通过后跳过，不根据未经确认的固件字段定义解析角速度。
噪声或坏校验使用滑动重同步；半帧字节间隔超过 20 ms 后重新找帧头。
串口错误或 256 槽接收队列溢出会丢弃缓冲并标记数据失效，随后重新同步。
应频繁 Poll；队列不是保证任意高输出频率或无限阻塞的缓存。

## 闭环用法（本次尚未实现控制器）

```c
HWT101_Poll();
if (HWT101_Read(&imu) && imu.sequence != last_sequence) {
    last_sequence = imu.sequence;
    error_deg = HWT101_AngleError(target_deg, imu.heading_deg);
    /* 按相邻 timestamp_ms 的间隔更新 PID，不能使用打印周期。 */
}
```

例如目标 -179、当前 +179，误差 +2 度；恰好 180 度时约定返回 -180。
只传入有限角度。目标和反馈必须使用相同参考零点。
连续角度要求相邻有效帧间真实转角小于 180 度，否则无法消除圈数歧义。
断线、接收溢出或串口错误后 continuous_valid 和 rate_valid 锁定失效，
即使重新收到 yaw 也不补猜丢失的转角，需重新发送 z 建立参考。
零点改变会改变控制参考，未来控制器应同步重置目标/积分项。
后续 PID 必须定义失联停机策略、合理的数据龄限制、限幅和电机正负方向对应关系。
软件归零和角度差分不消除陀螺长期漂移；启动静置时间按模块手册执行。

## 串口输出

S1/S2：最近采样窗口编码器增量；DT：该窗口毫秒数。
ANGLE：模块当前 Z 轴角度，单位度，保留两位小数，例如 ANGLE=18.61 deg。
相对角、连续角及差分角速度仍可通过驱动接口读取，当前串口只打印原始角和编码器数据。
无有效角度时输出 IMU=NO_DATA_OR_TIMEOUT，不把零值冒充有效航向。
r 清编码器；z 软件归零相对航向，不改变 ANGLE 显示的模块原始角。显示数值保留两位不等于实际精度两位。

## 模块命令

电脑调试串口使用 9600、8N1，文本发送单个字符（不要开启 HEX 发送）：
- c/C：模块 Z 轴归零，HWT101_ModuleZero()。
- b/B：模块重启，HWT101_Reboot()。不是恢复出厂设置。
- z/Z：保留软件相对角归零，不改变 ANGLE。
- r/R：保留编码器清零。

PA2 必须连接模块 RX。驱动先发解锁 FF AA 69 88 B5，至少间隔 20 ms，
再发归零 FF AA 76 00 00 或重启 FF AA 00 FF 00。
接口返回 1 仅表示本地接受请求，不代表模块执行确认；返回 0 表示忙或发送失败。
主循环必须持续 Poll；解锁后超过 10 秒未调度则放弃操作。
归零后隔离接收 500 ms，重启后隔离 1000 ms；这是主机保护间隔，不是执行确认。
期间 HWT101_IsBusy() 为真，输出 IMU=RESETTING，角度无效。
随后清理旧数据，等待有效新帧重新建立软件参考，不将复位角度跳变累计为运动。
接收恢复不证明命令执行成功，请检查实物角度变化。模块归零时应保持静止。
不发送保存配置、恢复出厂命令，也不在 MCU RESET 时自动重启模块。
