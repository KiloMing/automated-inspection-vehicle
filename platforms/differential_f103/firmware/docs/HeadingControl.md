# HWT101 航向闭环

采用角度外环与双电机速度内环。电机现有PID参数不变，外环宏在 Hardware/HeadingControl.h。
外环输出单位为计数/20ms，默认KP=1、KI=0、KD=0.10，最大50计数/20ms（约0.2m/s轮缘速度）。这些是待调参数，不能保证未经实车调整就达到特定精度。

## 方向配置

已确认电机1是左轮，电机2是右轮。两轮正PWM均推动车辆前进；HWT角度逆时针增加、顺时针减小。
当前main的UART1波特率为115200，仅接收控制指令，不输出遥测数据。具体状态可通过GetState或调试器查看。HWT101的USART2接收和闭环处理保持运行。

当前 main 运行蓝牙双摇杆遥控，不再解析早期定角测试使用的 g/r/h/s/z 命令。独立定角测试需要在主程序调用下面的接口；连续角失效后应先停车，再用 HWT101_Zero 恢复参考。

HEADING_MOTOR1_SIGN、HEADING_MOTOR2_SIGN 表示使HWT角度增大时，两台电机目标值的符号，分别填+1或-1。
已配置电机1为-1、电机2为+1，即左轮倒转、右轮正转使航向角增大。
还需保证各自编码器增量的正负与电机PWM正负一致。不能直接根据电机编号推断左右轮或安装方向。

## 接口

独立使用时，初始化 MotorControl、HWT101 和 HeadingControl，并持续调用 MotorControl_Process 与 HeadingControl_Process。不要与 RemoteControl 同时控制电机。

```c
/* 等待HWT101有有效连续角度后调用，检查返回值。 */
HeadingControl_Rotate(90.0f);  /* 相对当前角度增加90度，到位后保持 */
HeadingControl_Rotate(-90.0f); /* 相对当前角度减少90度 */
HeadingControl_Hold();        /* 捕获当前航向并持续抗扰 */
HeadingControl_Stop();        /* 停止且退出保持 */
```

已确认：正角度为逆时针，负角度为顺时针（从上往下看）。
使用连续角度，支持跨±180度边界和超过180度的指定方向转动；新命令相对实际当前角度计算，不是叠加上一次目标。
不要在每次循环重复发送Rotate/Hold，否则会不断重建目标。

角度误差进入1度内且角速度不超过3度/s时制动并进入HOLDING；偏离超过2度重新纠偏。
停止状态仍保存转向方向，反向纠偏前等待两轮速度接近零至少100ms。
传感器超过300ms无新角度、连续角无效、传感器命令忙或电机控制超时，进入FAULT并停止两轮；数据恢复不自动重启，需要重新下发命令。
数据中断后若连续角无效，应停车并使用HWT101_Zero恢复参考，再重新下发航向命令。
控制激活期间禁止HWT101清零/重启或其他模块直接下发电机目标。需要重置时先HeadingControl_Stop。

HWT101航向基于陀螺仪，长期漂移会影响保持的物理方向；该控制不能纠正传感器自身的漂移。
