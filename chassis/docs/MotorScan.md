# 电机2阶梯PWM扫描

VOFA设置：115200、8N1，协议FireWater。串口RX接PA9，TX接PA10，共地。
文本发送g开始、s停止，上电停止。电机1保持制动。
电机2从0%到100%，每秒增加2%，约51秒结束后自动停止。

每20ms输出一行，仅两个通道：

| 通道 | 内容 |
|---|---|
| 0 | 编码器有符号增量（本次采样窗口，不是累计计数） |
| 1 | PWM整数百分比（0到100） |

示例：25,50 后加换行，代表本窗口25个计数、50% PWM。
没有角度、RPM、状态、丢样数或提示文本。

电机2 PWMB=PB7，BIN1/2=PB14/15；编码器A/B=PA6/PA7（TIM3）。架空车轮测试。
TIM1每20ms采样，TIM4输出20kHz PWM，串口发送在主循环。
每圈2500计数，已包含四倍频，不再乘4；轮周长0.20m。
20ms下轮速RPM=增量*1.2，线速度m/s=增量*0.004。当前只发送原始增量与PWM。
换算接口仍保留：RPM=delta*60000/(2500*dt_ms)，线速度=RPM*0.20/60。

PWM切换窗口可能跨两个占空比，稳态拟合应选每级后半段数据。
单次采样计数变化绝对值必须小于32768。队列满会自动停止电机，诊断保留在内存中。
两个通道无法区分正常结束、手动停止或队列故障；需要时通过调试器查看状态。
HWT101驱动保留，但当前主程序不初始化、不输出，原r/z/c/b命令不使用。

测试：Tests/run_motor_scan.ps1；原解析回归：Tests/run_hwt101.ps1。
实物PWM、VOFA接收和轮速尚需上板验证。
